# Avatars

Déposer ici les images d'avatar (`.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`, `.gif`).
Elles apparaissent automatiquement dans « Modifier mon profil » (voir `src/utils/avatars.ts`).

Le profil enregistre le nom du fichier : ne pas renommer une image déjà choisie par des joueurs.
Carré conseillé, 256 × 256 px minimum.
